# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.x     | ✅        |

## Reporting a vulnerability

Please **do not open a public issue**. Report privately through
[GitHub Security Advisories](https://github.com/giaesp/x-fields/security/advisories/new).

Include the affected version, steps to reproduce and the impact. You will receive an
acknowledgement within 7 days; fixes are released as patch versions and credited in the changelog.
